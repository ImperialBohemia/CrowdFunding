# Analýza crowdfundingových platforem (ČR)

## Cíl: Bydlení a návrat dětí z ústavu k rodičům

### 1. Znesnáze21 (znesnaze21.cz) – DOPORUČENO / VÍTĚZ
* **Zaměření:** Sociální krize, rodiny, děti, ztráta bydlení.
* **Poplatky:** 0 % pro žadatele.
* **Exekuce:** Řešeno. Přímá úhrada pronajímateli a obchodům (peníze nejdou na zablokovaný účet).
* **Pomoc týmu:** Sociální pracovníci pomáhají formulovat text.
* **Potřebné doklady:** OP, rozhodnutí soudu / OSPOD, návrh nájemní smlouvy, rozpočet.

### 2. Donio.cz – ALTERNATIVA Č. 2
* **Zaměření:** Široké dobročinné sbírky s největším dosahem v ČR.
* **Poplatky:** 0 % pro zakladatele (financováno dýšky).
* **Exekuce:** Možné domluvit proplacení faktur třetím stranám po schválení.
* **Potřebné doklady:** OP, doložení sociální situace, rozpočet nákladů.

### 3. GoFundMe – NEPOUŽITELNÉ V ČR
* **Důvod:** ČR není podporovaná země pro výběr peněz na český bankovní účet.
* **Omezení:** Nutný garant s trvalým pobytem a bankou v podporované zemi (např. Německo).

### 4. Darujme.cz – NEPOUŽITELNÉ PRO JEDNOTLIVCE
* **Důvod:** Určeno výhradně pro registrované neziskové organizace (NNO), spolky a nadace.

### 5. Hithit / Startovač – NEPOUŽITELNÉ
* **Důvod:** Odměnový crowdfunding pro komerční, kreativní a produktové projekty.

## Doporučená strategie sbírky
* **Cílová částka:** Kauce (1–2 nájmy) + první nájmy + základní vybavení pro děti.
* **Forma úhrady:** Přímá fakturace majiteli bytu a dodavatelům nábytku.
* **Klíčový argument pro dárce:** Doložené stanovisko OSPOD/soudu o možnosti návratu dětí.
